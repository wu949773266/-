# 户外徒步 MBTI 玩法策划

## 核心定位

把普通 MBTI 改造成“山野场景人格测试”，让用户测完后觉得结果能指导真实徒步选择，而不只是娱乐标签。

推荐入口文案：

- 测测你在山里的隐藏人格
- 你是领队型、探路型，还是营地快乐型？
- 12 个徒步场景，找到你的户外搭子属性

## 可扩展玩法

### 1. 路线推荐

根据结果推荐路线类型：

- `SJ`：成熟经典线、补给稳定、时间节点明确
- `SP`：溯溪、攀爬、短促刺激、现场反馈强
- `NF`：风景叙事强、适合拍照和情绪体验
- `NT`：高线穿越、多日规划、小众探索

可以接你小程序里的路线库字段：

```js
{
  sceneTags: ['森林', '雪山', '湖泊'],
  intensity: '中等',
  routeStyle: ['经典', '小众', '挑战', '治愈'],
  suitableTypes: ['INFJ', 'INFP', 'ISFP']
}
```

### 2. 装备推荐

结果页可以接装备商城或装备清单：

- `J` 倾向：清单、收纳、备用电源、急救、导航
- `P` 倾向：轻量化、多功能、便携、可变组合
- `S` 倾向：耐用、真实口碑、稳定表现
- `N` 倾向：新装备、模块化、探索型工具

### 3. 组队匹配

可以做“最佳徒步搭子”：

- `ESTJ + ISFP`：一个控节奏，一个发现美
- `ENFP + ISTJ`：一个开脑洞，一个守边界
- `INFJ + ENTJ`：一个讲意义，一个推执行
- `ESFJ + INTP`：一个照顾人，一个研究路线

匹配页可以展示：

- 你适合当什么队伍角色
- 你需要什么类型队友补位
- 你可能和哪类人产生路线分歧

### 4. 分享海报

海报结构建议：

- 顶部：人格代号，比如 `INFP`
- 主标题：旷野理想派
- 中部：一句高识别度总结
- 下方：适合路线、装备关键词、队伍角色
- 底部：小程序码

视觉风格建议用真实山野照片做背景，比纯插画更有户外信任感。

### 5. 商业转化

测试完成后可以自然导向：

- 推荐 3 条适合路线
- 生成我的徒步装备清单
- 找同频徒步搭子
- 加入对应人格的路线团
- 领取新手徒步安全清单

## 内容语气

结果页要像“懂户外的人在解释你”，避免玄学感太重。关键词是：

- 真实场景
- 风险意识
- 装备建议
- 队伍协作
- 路线偏好

## 下一步优先级

1. 先接入组件，验证测试流程顺不顺。
2. 把 `complete` 事件里的 `typeCode` 接到你的路线库，做路线推荐。
3. 做分享海报，提升传播。
4. 再做组队匹配和装备清单。
